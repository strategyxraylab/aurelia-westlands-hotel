# AURELIA WESTLANDS HOTEL

Official website project for AURELIA WESTLANDS HOTEL, Westlands, Nairobi, Kenya.

## Website files

- `index.html` — Hotel homepage and content
- `style.css` — Responsive luxury black-and-gold design
- `script.js` — Navigation and reservation enquiry form handling
- `assets/images/` — Illustrative images representing hotel facilities

## Location

Along Waiyaki Way, opposite Westlands Market,
Westlands, Nairobi, Kenya.

## Contact

Email: aureliawestlandshotel@gmail.com

## Reservation enquiries

The website uses Formspree to deliver reservation enquiries to the hotel's email address. Submitting an enquiry does not confirm a reservation. All bookings are subject to hotel confirmation.

## Images

Website images are illustrative representations of the hotel's facilities.

## Publishing

The website is designed for static hosting through GitHub Pages.
